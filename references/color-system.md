# Corporate theme 2.1

Activity fill is neutral white (`#FFFFFF`); BPMN task type is conveyed by its
14–16 px marker, not by a fill color. A presentation `fill_override` is allowed
only with source provenance.

| Element | Fill |
|---|---|
| Human role overlay | `#6366F1` |
| System overlay | compact rounded badge, `#F3F4F6`, thin `#9CA3AF` stroke |
| System object | `#FFFFFF` |
| System report | `#FFDCC2` |
| Print form | `#E7FCCB` |

Color is never the only carrier of meaning.
